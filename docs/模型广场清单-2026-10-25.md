## 3. 价格口径：实付价、官方价、倍率是三件事

这一节是本窗口新增的核对结果，抄价格前务必先看懂：

| 概念 | 来源 | 含义 |
| --- | --- | --- |
| 分组倍率 | 分组对象上的 `rate_multiplier` | 该分组相对基准价的档位标签 |
| 实付价格(折后) | 接口 `pricing` 字段 **× 分组倍率** | 页面表格"实付价格(折后)"那一列 |
| 官方价格 | 接口 `official_pricing` 字段 | 厂商参考价 |

两条容易踩的坑：

1. **实付价 = 基准单价 × 分组倍率，不是"官方价 × 倍率"。** 官方价是厂商口径的参考值，和倍率之间没有固定算式；反过来用官方价乘倍率去估算自己会付多少，会算错。
2. **同一个模型在不同分组的实付价不同，这是设计而不是 bug。** 例如 `gpt-5.6-sol` 在 `Codex Plus`（0.088x）与 `Codex-企业稳定不降智`（0.3x）两个组里，上游通道和实付价都不一样。你买到的是"这个组的上游"，不是"这个模型"。

逐行的实付/官方价、长上下文分档与缓存价见[明细表 xlsx](模型广场清单-2026-10-25.xlsx)。

## 4. 怎么用这份清单

1. **先确认自己是哪个组**。Key 能访问哪些模型由分组决定；渠道正常但调用报 `404 model_not_found`，多半是分组不含该模型。登录控制台看分组名，再回到上面的分节找对应列表。
2. **抄模型名，不抄倍数**。倍率会变，模型名的字符不会自己变（下架除外）。`-preview` / 日期后缀都是不同条目。
3. **取模型清单只认 `GET /v1/models`**。它按你的 Key 所属分组返回，是唯一与"你这把 Key 真能调什么"对齐的入口，坑位见[《模型列表：怎么拿、怎么看》](模型列表获取与排错-2026-10-18.md)。
4. **算成本要看三件事**：分组倍率 × 输入输出 token 量 + 可能的系统前缀注入 + 缓存写入/读取的差别。前缀注入的实测方法与量级见[《模型真伪与防掺水检测方法学》](MODEL_VERIFICATION_METHODS.md)。
5. **不要拿本文的数字当现价**。页面还提示"登录后可查看你的专属分组与专属倍率"，公开倍率不等于你的实付价。

## 5. 口径与边界

| 本文能证明（B 级） | 本文不能证明 |
| --- | --- |
| 该窗口站点**列出的**模型名、分组与倍率 | 你的 Key 实际能调用成功 |
| 分组结构与相对档位 | 上游真的就是那个厂商的官方接口 |
| 站点当前声明的实付价与官方价 | 你最终按哪个价结算 |
| 同模型可以挂在不同倍率组 | 列表里的模型今天还能不能用 |

这与本仓库的证据纪律一致：公开接口返回属**声明**，不是调用结果。要判断"我付费调用的到底是不是它声称的模型"，看[《模型真伪与防掺水检测方法学》](MODEL_VERIFICATION_METHODS.md)。

另有三条实操提醒：

- `free` 组倍率极低但**不等于免费**，且历史上有过越过平台门直接返回 404 的行为，先用最小请求验证。
- 「模型出现在列表里」只说明接口返回了该名称，**不等于**当前 Key、分组与上游账号池一定可调用。
- 图像/视频模型的计价单位与文本不同（按张、按秒），别用 token 单价横向比较。

## 6. 怎么自己核对

不用登录、不用 Key、不花钱，直接拉公开接口：

```bash
curl -sS https://nuoapi.net/api/v1/model-plaza
```

返回结构：`data.groups[]` 是分组（`name` / `rate_multiplier` / `platform`），每个分组的 `models[]` 是模型（`name` / `platform` / `pricing` / `official_pricing`）；`pricing.intervals[]` 带 `tier_label` 与分档单价。

只想看模型名：

```bash
curl -sS https://nuoapi.net/api/v1/model-plaza \
  | python -c "import sys,json;d=json.load(sys.stdin)['data'];[print(g['name'],g['rate_multiplier'],m['name']) for g in d['groups'] for m in g['models']]"
```

想看页面本身，就打开模型广场，用「平台」筛协议族、「分组」选你 Key 所属的组、「倍率」收窄价格档，再在模型框里搜名字。

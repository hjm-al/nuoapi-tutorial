## 3. 怎么用这份清单

1. **不要从本文抄当前模型名**。本文只保留 10-12 窗口的页面原文。现在要填进客户端的名字，逐字符照抄[10-25 清单](模型广场清单-2026-10-25.md)或当前 Key 的 `/v1/models`。后缀（`-preview`、日期）在当时就是不同条目，原文不改写。
2. **核对分组**：Key 能访问哪些模型由它所属分组决定。渠道正常但调用报 `model not found`，多半是分组不包含该模型。
3. **看计费口径**：第 2 节给的是「实付输入 / 实付输出」两列（已折后的价），单位 `$ / 1M token`；明细表里另有「官方」列（官方价）与倍率列。图片模型按张、视频模型按秒，已在单元格内单独标注。
4. **分层定价**：不少模型按上下文长度或时段分价（如 `<200K` / `≥200K`、`01:00–04:00` 与 `06:00–10:00` 两个折扣时段），清单按页面原样保留。

- 表中 `写` / `读` 指缓存写入 / 缓存读取价格；`-` 表示页面未给出该项。第 2 节为篇幅只列了输入/输出两列，缓存与官方价看[明细表](模型广场清单-2026-10-12.xlsx)。
- `free` 分组倍率为 `0.001x`，但**不等于免费**，且该分组历史上出现过越过平台门直接返回 404 的行为（见侦察档案），配置前先用最小请求验证。
- 「模型出现在列表里」只说明列表接口返回了该名称，**不等于**当前 Key、分组与上游账号池一定调用成功；真伪与能力只能写成「匹配 / 不匹配 / 证据不足」。
- 本清单是 2026-10-12 的历史窗口，之后的上架、下架和倍率变化都不会回写到这里。抄名字用[模型广场清单（10-25）](模型广场清单-2026-10-25.md)。
- 页面会提示「登录后可查看你的专属分组与专属倍率」：**公开倍率 ≠ 你的实付倍率**，拿它做预算时留余量。

## 3. 怎么用这份清单

1. **先确认自己是哪个组**。Key 能访问哪些模型由分组决定；渠道正常但调用报 `404 model_not_found`，多半是分组不含该模型。登录控制台看分组名，再回到上面的分节找对应列表。
2. **抄模型名，不抄倍数**。倍率会变，模型名的字符不会自己变（下架除外）。`-preview` / 日期后缀都是不同条目。
3. **算成本要看三件事**：分组倍率 × 输入输出 token 量 + 可能的系统前缀注入 + 缓存写入/读取的差别。前缀注入的实测方法与量级见[《模型真伪与防掺水检测方法学》](MODEL_VERIFICATION_METHODS.md)。
4. **不要拿本文的数字当现价**。页面上还有一档"登录后可见的专属倍率"，公开表可能与你实际结算不同。

## 4. 口径与边界

| 本文能证明（B 级） | 本文不能证明 |
| --- | --- |
| 该窗口页面**列出的**模型名与分组倍率 | 你的 Key 实际能调用成功 |
| 分组结构与相对档位 | 上游真的就是那个厂商的官方接口 |
| 同模型可以挂在不同倍率组 | 你最终按哪个倍率结算 |

这与本仓库的证据纪律一致：页面列表属**声明**，不是调用结果。要判断"我付费调用的到底是不是它声称的模型"，看[《模型真伪与防掺水检测方法学》](MODEL_VERIFICATION_METHODS.md)。

另有三条实操提醒：

- `free` 组倍率极低但**不等于免费**，且历史上有过越过平台门直接返回 404 的行为，先用最小请求验证。
- 「模型出现在列表里」只说明页面渲染了该名称，**不等于**当前 Key、分组与上游账号池一定可调用。
- 图像/视频模型的计价单位与文本不同（按张、按秒），别用 token 单价横向比较。

## 5. 怎么自己核对

1. 打开模型广场（地址从仓库 README 的实例说明或控制台入口进）。
2. 用「平台」筛掉不相关的协议族，再用「分组」选你 Key 所属的组，「倍率」可进一步收窄价格档。
3. 表格三列为 `实付价格(折后)` / `官方价格` / `折扣倍率`，单位 `$ / 1M token`；图片按张、视频按秒会单独标注。
4. 记下你自己的观察时间（本地时间即可）。**不需要登录，也不要为核对价格发起任何计费请求。**

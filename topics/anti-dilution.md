# 防掺水检测：开源 Python 模型真伪取证探针

这一页只回答一件事：怎样用仓库里的 Python 探针留下可复核的证据，而不是问模型“你是谁”。结论只写 **匹配 / 不匹配 / 证据不足**。证据不足就继续取样，不能写成通过。

> **主操作**：先运行 `python examples/model_verify.py --selftest`。这一步不联网、不发送计费请求，只核对探针和统计口径。

样例端点用[模型广场](https://nuoapi.net/model-plaza)做地址夹具。方法不绑定这一家；换端点时只替换地址和模型名。统计口径、假阳性回归和四档信号的边界在[模型真伪与防掺水方法学](../docs/MODEL_VERIFICATION_METHODS.md)，本页不另写一套标准。

## 探针做什么

[`model_verify.py`](../examples/model_verify.py) 是零第三方依赖的开源脚本，默认不带 `--run` 就只打印计划。三段对应三种无法靠自述伪装的痕迹：

| 段 | 看什么 | 不看什么 |
|---|---|---|
| A | 同一协议入口上的响应骨架、`id` 形状、`usage` 字段名 | 模型自己报出的厂牌 |
| B | 同样本量下的输出分布；闭集题和开放题分开统计 | 单次回答快不快 |
| C | 长上下文里调用方自己埋下的暗号是否还在 | 公开脑筋急转弯对没对 |

只有 A/B/C 能支撑“不匹配”。模型自述、拒答话术和首字延迟只记录，不参与判定。禁止把“没出现某个厂牌词”或“响应很快”写成掺水结论。

## 什么时候才发请求

离线自检通过后，仍不要直接加 `--run`。先看脚本打印的预计请求条数和 token。B 段默认是多道窄约束探针重复取样，费用随分组倍率变化，以控制台记录为准，不在这里报一个总价。

声称的协议必须和实际路径一致：标成 Anthropic 却去打 `/v1/chat/completions`，再用另一套字段表核对，得到的“不匹配”是对照表用错了。
